# Balatro Vocaloid

Adds a Vocaloid themed deck and changes the jokers and icons to be Vocaloid themed

Currently unfinished but works

## Config

config.lua can be changed to decide what the mod applies, such as not changing the joker appearances

```lua
 -- Whether to try change the word Joker to Miku in the games text.
 -- Default: true
 ["ChangeText"] = true,

 -- Whether to change the Joker atlas.
 -- Default: true
 ["ChangeJokerAtlas"] = true,

 -- Whether to change the Icon atlas.
 -- Default: true
 ["ChangeIcons"] = true,

 -- Whether to change the text colours used for the cards.
 -- Default: true
 ["ChangeTextColours"] = true,
```
